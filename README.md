# Світло за графіком – APK releases

Android app for the Zhytomyroblenergo power outage schedule (the same page as https://dmitryzemlyuk.github.io/svitlo/, plus home-screen widgets and notifications). This repository holds **APK builds only**, no sources.

- **Install:** download the newest `apk/svitlo-<version>.apk` and open it on the phone. Latest: see [`latest.json`](latest.json).
- **Updates:** the app (1.0.4 and newer) checks `latest.json` here about once a day, announces a new version with a notification and updates itself. Updates install over the previous version and keep all addresses and settings (same signing key).
- Only the last 3 versions are kept here; older releases and APKs are removed automatically.
- Requires Android 8.0 or newer.
